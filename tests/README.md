# Shared contract fixtures & evidence

`telemetry.sample.json`, `event.sample.json` dùng làm mẫu khi chưa có ESP32. Bất kỳ thay đổi tên/kiểu trường đều phải cập nhật song song firmware, backend, frontend và file mẫu này trong cùng PR hoặc trong PR phối hợp.

Bằng chứng test gồm: câu lệnh/steps chạy, expected/actual, ảnh hoặc log, link Wokwi, ghi chú lỗi chưa xử lý. Tránh commit định vị GPS cá nhân thật hoặc secrets.
